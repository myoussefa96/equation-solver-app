# Engine Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the pure-Dart math engine for the equation-solver mobile app — tokenizer, AST, OpRegistry (single source of truth for operators), parser, evaluator, dependency resolver, error model, and legacy importer — covered by unit tests and a golden test that imports all 15 legacy formulas from the Django dump.

**Architecture:** Pure Dart, zero Flutter imports. Lives under `lib/engine/` of the Flutter project. The block builder (later plan) constructs ASTs directly; the parser exists only for legacy import and a power-user "paste a formula" affordance. All operator/function knowledge concentrates in `OpRegistry` — adding a new operation is one map entry and the UI/parser/evaluator all pick it up. Evaluator is a pure recursive walk; dependency resolver uses Kahn's algorithm for topological sort and cycle detection.

**Tech Stack:** Dart 3.x (Flutter SDK), `test` package, `meta` for `@immutable`, no Flutter imports in engine. Spec at `docs/superpowers/specs/2026-05-22-equation-app-mobile-renovation-design.md`.

import 'package:meta/meta.dart';

@immutable
sealed class AstNode {
  const AstNode();
}

@immutable
class NumberLit extends AstNode {
  final double value;
  const NumberLit(this.value);

  @override
  bool operator ==(Object other) =>
      identical(this, other) || (other is NumberLit && other.value == value);

  @override
  int get hashCode => value.hashCode;

  @override
  String toString() => 'NumberLit($value)';
}

@immutable
class Identifier extends AstNode {
  final String name;
  const Identifier(this.name);

  @override
  bool operator ==(Object other) =>
      identical(this, other) || (other is Identifier && other.name == name);

  @override
  int get hashCode => name.hashCode;

  @override
  String toString() => 'Identifier($name)';
}

@immutable
class UnaryMinus extends AstNode {
  final AstNode operand;
  const UnaryMinus(this.operand);

  @override
  bool operator ==(Object other) =>
      identical(this, other) || (other is UnaryMinus && other.operand == operand);

  @override
  int get hashCode => Object.hash('unary-', operand);

  @override
  String toString() => 'UnaryMinus($operand)';
}

@immutable
class BinaryOp extends AstNode {
  final String op;          // one of: + - * / ^
  final AstNode left;
  final AstNode right;
  const BinaryOp(this.op, this.left, this.right);

  @override
  bool operator ==(Object other) =>
      identical(this, other) ||
      (other is BinaryOp && other.op == op && other.left == left && other.right == right);

  @override
  int get hashCode => Object.hash(op, left, right);

  @override
  String toString() => 'BinaryOp($op, $left, $right)';
}

@immutable
class FunctionCall extends AstNode {
  final String name;
  final List<AstNode> args;
  const FunctionCall(this.name, this.args);

  @override
  bool operator ==(Object other) {
    if (identical(this, other)) return true;
    if (other is! FunctionCall) return false;
    if (other.name != name || other.args.length != args.length) return false;
    for (var i = 0; i < args.length; i++) {
      if (other.args[i] != args[i]) return false;
    }
    return true;
  }

  @override
  int get hashCode => Object.hash(name, Object.hashAll(args));

  @override
  String toString() => 'FunctionCall($name, $args)';
}
```

import 'ast.dart';

/// Serialize an AST node to a JSON-safe Map.
Map<String, Object?> astToJson(AstNode node) {
  return switch (node) {
    NumberLit(:final value) => {'type': 'NumberLit', 'value': value},
    Identifier(:final name) => {'type': 'Identifier', 'name': name},
    UnaryMinus(:final operand) => {
        'type': 'UnaryMinus',
        'operand': astToJson(operand),
      },
    BinaryOp(:final op, :final left, :final right) => {
        'type': 'BinaryOp',
        'op': op,
        'left': astToJson(left),
        'right': astToJson(right),
      },
    FunctionCall(:final name, :final args) => {
        'type': 'FunctionCall',
        'name': name,
        'args': args.map(astToJson).toList(),
      },
  };
}

/// Deserialize a JSON Map back to an AST node.
/// Throws [FormatException] if the structure is malformed.
AstNode astFromJson(Map<String, Object?> json) {
  final type = json['type'];
  return switch (type) {
    'NumberLit' => NumberLit((json['value'] as num).toDouble()),
    'Identifier' => Identifier(json['name'] as String),
    'UnaryMinus' => UnaryMinus(
        astFromJson(json['operand']! as Map<String, Object?>)),
    'BinaryOp' => BinaryOp(
        json['op'] as String,
        astFromJson(json['left']! as Map<String, Object?>),
        astFromJson(json['right']! as Map<String, Object?>),
      ),
    'FunctionCall' => FunctionCall(
        json['name'] as String,
        (json['args']! as List)
            .map((a) => astFromJson(a as Map<String, Object?>))
            .toList(),
      ),
    _ => throw FormatException('Unknown AST node type: $type'),
  };
}

// Operator precedence table — higher = tighter binding.
// Used by the pretty-printer to decide where parens are needed.
const Map<String, int> _opPrec = {'+': 1, '-': 1, '*': 2, '/': 2, '^': 3};
const Set<String> _rightAssoc = {'^'};

/// Pretty-print an AST back to formula text. Inverse of the parser:
/// `prettyPrint(astFromJson(astToJson(parser.parse(text))))` ≈ `text` modulo whitespace.
String prettyPrint(AstNode node) {
  return switch (node) {
    NumberLit(:final value) => value.toString(),
    Identifier(:final name) => name,
    UnaryMinus(:final operand) => '-${_wrapForUnary(operand)}',
    BinaryOp(:final op, :final left, :final right) =>
      '${_wrapForBinary(left, op, isLeft: true)} $op '
      '${_wrapForBinary(right, op, isLeft: false)}',
    FunctionCall(:final name, :final args) =>
      '$name(${args.map(prettyPrint).join(', ')})',
  };
}

String _wrapForBinary(AstNode child, String parentOp, {required bool isLeft}) {
  if (child is BinaryOp) {
    final childPrec = _opPrec[child.op]!;
    final parentPrec = _opPrec[parentOp]!;
    if (childPrec < parentPrec) return '(${prettyPrint(child)})';
    if (childPrec == parentPrec) {
      // Same precedence: right-assoc ops need parens on the LEFT child;
      // left-assoc ops need parens on the RIGHT child.
      final rightAssoc = _rightAssoc.contains(parentOp);
      final needsParens = rightAssoc ? isLeft : !isLeft;
      if (needsParens) return '(${prettyPrint(child)})';
    }
  }
  return prettyPrint(child);
}

String _wrapForUnary(AstNode child) {
  if (child is BinaryOp) return '(${prettyPrint(child)})';
  return prettyPrint(child);
}
```

```dart
import 'package:meta/meta.dart';

enum TokenKind {
  number,
  identifier,
  plus,
  minus,
  star,
  slash,
  caret,
  lparen,
  rparen,
  comma,
  equals,
  eof,
}

@immutable
class Token {
  final TokenKind kind;
  final String lexeme;
  final int pos;
  final double? numericValue;
  const Token(this.kind, this.lexeme, this.pos, {this.numericValue});

  @override
  String toString() => 'Token($kind, "$lexeme", pos=$pos)';
}

class Tokenizer {
  final String src;
  int _i = 0;

  Tokenizer(this.src);

  List<Token> tokenize() {
    final out = <Token>[];
    while (_i < src.length) {
      final c = src[_i];
      if (_isWhitespace(c)) {
        _i++;
        continue;
      }
      if (_isDigit(c) || (c == '.' && _i + 1 < src.length && _isDigit(src[_i + 1]))) {
        out.add(_number());
        continue;
      }
      if (_isAlpha(c) || c == '_') {
        out.add(_identifier());
        continue;
      }
      final single = switch (c) {
        '+' => TokenKind.plus,
        '-' => TokenKind.minus,
        '*' => TokenKind.star,
        '/' => TokenKind.slash,
        '^' => TokenKind.caret,
        '(' => TokenKind.lparen,
        ')' => TokenKind.rparen,
        ',' => TokenKind.comma,
        '=' => TokenKind.equals,
        _ => null,
      };
      if (single != null) {
        out.add(Token(single, c, _i));
        _i++;
        continue;
      }
      throw FormatException('Unexpected character "${c}" at position $_i', src, _i);
    }
    out.add(Token(TokenKind.eof, '', _i));
    return out;
  }

  Token _number() {
    final start = _i;
    while (_i < src.length && _isDigit(src[_i])) _i++;
    if (_i < src.length && src[_i] == '.') {
      _i++;
      while (_i < src.length && _isDigit(src[_i])) _i++;
    }
    if (_i < src.length && (src[_i] == 'e' || src[_i] == 'E')) {
      _i++;
      if (_i < src.length && (src[_i] == '+' || src[_i] == '-')) _i++;
      if (_i >= src.length || !_isDigit(src[_i])) {
        throw FormatException(
            'Malformed exponent at position $_i', src, _i);
      }
      while (_i < src.length && _isDigit(src[_i])) _i++;
    }
    final lexeme = src.substring(start, _i);
    final value = double.parse(lexeme);
    return Token(TokenKind.number, lexeme, start, numericValue: value);
  }

  Token _identifier() {
    final start = _i;
    while (_i < src.length && (_isAlpha(src[_i]) || _isDigit(src[_i]) || src[_i] == '_')) {
      _i++;
    }
    final lexeme = src.substring(start, _i);
    return Token(TokenKind.identifier, lexeme, start);
  }

  static bool _isDigit(String c) => c.codeUnitAt(0) >= 0x30 && c.codeUnitAt(0) <= 0x39;
  static bool _isAlpha(String c) {
    final u = c.codeUnitAt(0);
    return (u >= 0x41 && u <= 0x5A) || (u >= 0x61 && u <= 0x7A);
  }
  static bool _isWhitespace(String c) => c == ' ' || c == '\t' || c == '\n' || c == '\r';
}

import 'package:meta/meta.dart';
import 'ast.dart';
import 'tokenizer.dart';

@immutable
class Assignment {
  final String lhs;
  final AstNode rhs;
  const Assignment(this.lhs, this.rhs);
}

class Parser {
  final List<Token> _tokens;
  int _i = 0;

  Parser(String src) : _tokens = Tokenizer(src).tokenize();

  /// Parse the entire input as a single expression. Throws on trailing tokens.
  AstNode parseExpression() {
    final node = _expression(0);
    if (_peek().kind != TokenKind.eof) {
      throw FormatException(
          'Unexpected token "${_peek().lexeme}" at position ${_peek().pos}');
    }
    return node;
  }

  /// Parse `IDENT '=' expression`. Throws if input doesn't match.
  Assignment parseAssignment() {
    final lhs = _consume(TokenKind.identifier, 'identifier on left of "="').lexeme;
    _consume(TokenKind.equals, '"=" between LHS and expression');
    final rhs = _expression(0);
    if (_peek().kind != TokenKind.eof) {
      throw FormatException(
          'Unexpected token "${_peek().lexeme}" at position ${_peek().pos}');
    }
    return Assignment(lhs, rhs);
  }

  // ---- Pratt-style precedence climbing ----

  AstNode _expression(int minPrec) {
    AstNode lhs = _atom();
    while (true) {
      final tok = _peek();
      final op = _binaryOpFor(tok.kind);
      if (op == null) break;
      final prec = _binaryPrec[op]!;
      if (prec < minPrec) break;
      _advance();
      final rightAssoc = _rightAssoc.contains(op);
      final nextMin = rightAssoc ? prec : prec + 1;
      final rhs = _expression(nextMin);
      lhs = BinaryOp(op, lhs, rhs);
    }
    return lhs;
  }

  AstNode _atom() {
    final tok = _peek();
    switch (tok.kind) {
      case TokenKind.minus:
        _advance();
        return UnaryMinus(_atom());
      case TokenKind.plus:
        _advance();
        return _atom(); // unary plus is a no-op
      case TokenKind.number:
        _advance();
        return NumberLit(tok.numericValue!);
      case TokenKind.identifier:
        _advance();
        if (_peek().kind == TokenKind.lparen) {
          _advance(); // consume (
          final args = <AstNode>[];
          if (_peek().kind != TokenKind.rparen) {
            args.add(_expression(0));
            while (_peek().kind == TokenKind.comma) {
              _advance();
              args.add(_expression(0));
            }
          }
          _consume(TokenKind.rparen, '")" after function arguments');
          return FunctionCall(tok.lexeme, args);
        }
        return Identifier(tok.lexeme);
      case TokenKind.lparen:
        _advance();
        final inner = _expression(0);
        _consume(TokenKind.rparen, '")" to close group');
        return inner;
      default:
        throw FormatException(
            'Expected number, identifier, or "(", got "${tok.lexeme}" at position ${tok.pos}');
    }
  }

  static const Map<String, int> _binaryPrec = {
    '+': 1, '-': 1,
    '*': 2, '/': 2,
    '^': 3,
  };
  static const Set<String> _rightAssoc = {'^'};

  String? _binaryOpFor(TokenKind k) => switch (k) {
        TokenKind.plus => '+',
        TokenKind.minus => '-',
        TokenKind.star => '*',
        TokenKind.slash => '/',
        TokenKind.caret => '^',
        _ => null,
      };

  Token _peek() => _tokens[_i];
  Token _advance() => _tokens[_i++];

  Token _consume(TokenKind kind, String what) {
    final tok = _peek();
    if (tok.kind != kind) {
      throw FormatException('Expected $what but got "${tok.lexeme}" at position ${tok.pos}');
    }
    return _advance();
  }
}

import 'dart:math' as math;
import 'ast.dart';
import 'errors.dart';
import 'op_registry.dart';

class Evaluator {
  final Map<String, double> scope;
  const Evaluator({this.scope = const {}});

  /// Evaluate an AST. Throws an [EngineError] subclass on failure.
  double eval(AstNode node) {
    final v = _evalInternal(node);
    if (v.isNaN || v.isInfinite) {
      throw EvalError(
        'Result is undefined (likely a divide-by-zero or out-of-range value upstream).',
        node,
      );
    }
    return v;
  }

  double _evalInternal(AstNode node) {
    return switch (node) {
      NumberLit(:final value) => value,
      Identifier(:final name) => _lookup(name),
      UnaryMinus(:final operand) => -_evalInternal(operand),
      BinaryOp(:final op, :final left, :final right) =>
        _applyBinary(op, _evalInternal(left), _evalInternal(right), node),
      FunctionCall(:final name, :final args) =>
        _applyFunction(name, args.map(_evalInternal).toList(growable: false), node),
    };
  }

  double _lookup(String name) {
    if (scope.containsKey(name)) return scope[name]!;
    final c = OpRegistry.constants[name];
    if (c != null) return c;
    throw UnknownIdentifierError(name);
  }

  double _applyBinary(String op, double a, double b, AstNode location) {
    switch (op) {
      case '+': return a + b;
      case '-': return a - b;
      case '*': return a * b;
      case '/':
        if (b == 0) throw EvalError('Can\'t divide by zero.', location);
        return a / b;
      case '^':
        if (a == 0 && b < 0) {
          throw EvalError('Can\'t raise 0 to a negative power.', location);
        }
        if (a < 0 && b != b.roundToDouble()) {
          throw EvalError(
            'Can\'t raise a negative number ($a) to a non-integer power ($b).',
            location,
          );
        }
        return math.pow(a, b).toDouble();
      default:
        throw EvalError('Unknown operator "$op".', location);
    }
  }

  double _applyFunction(String name, List<double> args, AstNode location) {
    final def = OpRegistry.lookup(name);
    if (def == null) {
      throw EvalError('"$name" isn\'t a function the app knows about.', location);
    }
    if (def.arity != -1 && def.arity != args.length) {
      throw EvalError(
        '"$name" needs ${def.arity} argument(s) but got ${args.length}.',
        location,
      );
    }
    if (name == 'sqrt' || name == 'root') {
      if (args[0] < 0) {
        throw EvalError('Can\'t take the square root of ${args[0]}.', location);
      }
    }
    if (name == 'ln' || name == 'log') {
      if (args[0] <= 0) {
        throw EvalError('Can\'t take the logarithm of ${args[0]}.', location);
      }
    }
    return def.impl(args);
  }
}

import 'package:meta/meta.dart';
import 'ast.dart';
import 'errors.dart';
import 'op_registry.dart';

enum VarRole { input, intermediate, output }

@immutable
class EqEntry {
  final String output;
  final AstNode ast;
  const EqEntry({required this.output, required this.ast});
}

@immutable
class ResolveResult {
  final List<String> order;                  // topo-sorted output names
  final Map<String, VarRole> roles;          // every non-constant identifier
  const ResolveResult(this.order, this.roles);
}

@immutable
class DuplicateOutputError extends EngineError {
  final String name;
  const DuplicateOutputError(this.name);

  @override
  String get userMessage =>
      'Two formulas assign "$name". Only one formula can compute each variable.';
}

abstract final class DependencyResolver {
  /// Resolve dependencies for a set of equations belonging to one entry.
  ///
  /// [declaredVariables] is the set of identifiers the user has declared via
  /// the builder's "Add a variable" sheet, mapped to their roles if known
  /// (null = unknown; resolver will classify). Pass `{}` if you only want to
  /// classify based on AST usage.
  ///
  /// Returns the topo-sorted output order and role map.
  /// Throws [CycleError] or [DuplicateOutputError].
  static ResolveResult resolve(
    List<EqEntry> equations, {
    Map<String, VarRole?> declaredVariables = const {},
  }) {
    // 1. Check for duplicate outputs.
    final seen = <String>{};
    for (final e in equations) {
      if (!seen.add(e.output)) {
        throw DuplicateOutputError(e.output);
      }
    }

    // 2. Collect every referenced identifier (excluding constants).
    final refs = <String, Set<String>>{}; // output -> set of identifiers in its RHS
    final allIds = <String>{};
    for (final e in equations) {
      final ids = _collectIds(e.ast);
      refs[e.output] = ids;
      allIds.addAll(ids);
      allIds.add(e.output);
    }
    allIds.addAll(declaredVariables.keys);

    // 3. Build outputs set (= LHS of all equations).
    final outputs = equations.map((e) => e.output).toSet();

    // 4. Build edges: rhs-id -> lhs (only if rhs-id is also a LHS of some equation).
    final edgesOut = <String, Set<String>>{
      for (final e in equations) e.output: <String>{},
    };
    final inDegree = <String, int>{
      for (final e in equations) e.output: 0,
    };
    for (final e in equations) {
      for (final id in refs[e.output]!) {
        if (outputs.contains(id)) {
          edgesOut[id]!.add(e.output);
          inDegree[e.output] = inDegree[e.output]! + 1;
        }
      }
    }

    // 5. Kahn's algorithm.
    final queue = <String>[
      for (final e in equations)
        if (inDegree[e.output] == 0) e.output,
    ];
    final order = <String>[];
    while (queue.isNotEmpty) {
      final n = queue.removeAt(0);
      order.add(n);
      for (final m in edgesOut[n]!) {
        inDegree[m] = inDegree[m]! - 1;
        if (inDegree[m] == 0) queue.add(m);
      }
    }

    if (order.length != equations.length) {
      // Cycle exists. Collect remaining nodes for the message.
      final remaining = [
        for (final e in equations)
          if (inDegree[e.output]! > 0) e.output,
      ];
      throw CycleError(remaining);
    }

    // 6. Classify roles.
    final roles = <String, VarRole>{};
    for (final id in allIds) {
      if (OpRegistry.constants.containsKey(id)) continue;
      final isOutput = outputs.contains(id);
      if (!isOutput) {
        roles[id] = VarRole.input;
        continue;
      }
      // It's an output. Determine if any later equation references it.
      final referencedByOther = equations
          .where((e) => e.output != id)
          .any((e) => refs[e.output]!.contains(id));
      roles[id] = referencedByOther ? VarRole.intermediate : VarRole.output;
    }

    return ResolveResult(order, roles);
  }

  static Set<String> _collectIds(AstNode node) {
    final out = <String>{};
    void walk(AstNode n) {
      switch (n) {
        case NumberLit():
          break;
        case Identifier(:final name):
          if (!OpRegistry.constants.containsKey(name)) out.add(name);
          break;
        case UnaryMinus(:final operand):
          walk(operand);
          break;
        case BinaryOp(:final left, :final right):
          walk(left);
          walk(right);
          break;
        case FunctionCall(:final args):
          for (final a in args) walk(a);
          break;
      }
    }
    walk(node);
    return out;
  }
}

String slugify(String label) {
  final sb = StringBuffer();
  for (final r in label.runes) {
    final c = String.fromCharCode(r);
    if (_isAllowed(c)) {
      sb.write(c);
    } else {
      sb.write('_');
    }
  }
  var s = sb.toString();
  // Collapse runs of underscores and trim leading/trailing.
  s = s.replaceAll(RegExp(r'_+'), '_');
  s = s.replaceAll(RegExp(r'^_+|_+$'), '');
  if (s.isEmpty) return '_';
  // Identifier must not start with a digit.
  if (RegExp(r'^[0-9]').hasMatch(s)) s = '_$s';
  return s;
}

bool _isAllowed(String c) {
  final u = c.codeUnitAt(0);
  return (u >= 0x30 && u <= 0x39) // 0-9
      || (u >= 0x41 && u <= 0x5A) // A-Z
      || (u >= 0x61 && u <= 0x7A) // a-z
      || c == '_';
}

class SlugAllocator {
  final Set<String> _used;
  SlugAllocator({Set<String> reserved = const {}}) : _used = {...reserved};

  String allocate(String label) {
    final base = slugify(label);
    if (!_used.contains(base)) {
      _used.add(base);
      return base;
    }
    var n = 2;
    while (_used.contains('${base}_$n')) {
      n++;
    }
    final result = '${base}_$n';
    _used.add(result);
    return result;
  }
}

import 'package:meta/meta.dart';
import 'ast.dart';
import 'dependency_resolver.dart';
import 'op_registry.dart';
import 'parsed_entry.dart';
import 'parser.dart';
import 'slugify.dart';

@immutable
class SkippedEntry {
  final String entryName;
  final String reason;
  const SkippedEntry(this.entryName, this.reason);
}

@immutable
class ImportReport {
  final List<ParsedFolder> folders;
  final List<SkippedEntry> skipped;
  const ImportReport(this.folders, this.skipped);
}

abstract final class LegacyImporter {
  /// Import a seed JSON map (the shape produced by `tool/build_seed.dart`).
  /// Throws on structural errors. Skips individual entries that fail to parse;
  /// see [importSeedWithReport] if you want the skip list.
  static List<ParsedFolder> importSeed(Map<String, Object?> seed) =>
      importSeedWithReport(seed).folders;

  static ImportReport importSeedWithReport(Map<String, Object?> seed) {
    final foldersRaw = (seed['folders'] as List).cast<Map<String, Object?>>();
    final entriesRaw = (seed['entries'] as List).cast<Map<String, Object?>>();

    final folders = <int, List<ParsedEntry>>{
      for (final f in foldersRaw) f['old_id']! as int: <ParsedEntry>[],
    };
    final folderNames = <int, String>{
      for (final f in foldersRaw) f['old_id']! as int: f['name']! as String,
    };
    final skipped = <SkippedEntry>[];

    for (final raw in entriesRaw) {
      final name = raw['name']! as String;
      try {
        final entry = _importOne(raw);
        final oldFolderId = raw['old_folder_id']! as int;
        folders[oldFolderId]!.add(entry);
      } on FormatException catch (e) {
        skipped.add(SkippedEntry(name, e.message));
      } on Exception catch (e) {
        skipped.add(SkippedEntry(name, e.toString()));
      }
    }

    final parsedFolders = [
      for (final f in foldersRaw)
        ParsedFolder(
          name: folderNames[f['old_id']!]!,
          entries: folders[f['old_id']!]!,
        ),
    ];
    return ImportReport(parsedFolders, skipped);
  }

  static ParsedEntry _importOne(Map<String, Object?> raw) {
    final name = raw['name']! as String;
    final description = (raw['description'] as String?)?.trim();
    final equationsRaw = (raw['equations_raw']! as String).trim();
    final variablesRaw = (raw['variables_raw'] as String?) ?? '';
    final finalvarsRaw = (raw['finalvars_raw'] as String?) ?? '';

    // 1. Split top-level commas (legacy convention: one entry can hold many
    //    chained equations separated by commas).
    final pieces = _splitTopLevelCommas(equationsRaw);

    // 2. Parse each as `LHS = RHS`.
    final allocator = SlugAllocator(reserved: OpRegistry.constants.keys.toSet());
    final labelToId = <String, String>{};
    String idFor(String label) {
      final trimmed = label.trim();
      if (trimmed.isEmpty) {
        throw FormatException('Empty variable label');
      }
      return labelToId.putIfAbsent(trimmed, () => allocator.allocate(trimmed));
    }

    final equations = <EqEntry>[];
    final equationsParsed = <ParsedEquation>[];
    for (final piece in pieces) {
      // Split on top-level "=" — the LHS may be a free-form label like
      // "y(t) air" that isn't a valid identifier in our grammar.
      final eqIdx = _findTopLevelEquals(piece);
      if (eqIdx < 0) {
        throw FormatException('Missing "=" in legacy formula: "$piece"');
      }
      final lhsLabel = piece.substring(0, eqIdx);
      final rhsText = piece.substring(eqIdx + 1);
      final lhsId = idFor(lhsLabel);
      final rhsAst = Parser(rhsText).parseExpression();
      final remappedAst = _remapAst(rhsAst, idFor);
      equations.add(EqEntry(output: lhsId, ast: remappedAst));
      equationsParsed.add(ParsedEquation(outputVar: lhsId, ast: remappedAst));
    }

    // 3. Pre-declare any variables listed in variables_raw.
    final declaredLabels = variablesRaw
        .split(',')
        .map((s) => s.trim())
        .where((s) => s.isNotEmpty);
    final declared = <String, VarRole?>{};
    for (final lbl in declaredLabels) {
      declared[idFor(lbl)] = null;
    }

    // 4. Resolve.
    final resolved = DependencyResolver.resolve(equations,
        declaredVariables: declared);

    // 5. Build variable list with finalvars flagging.
    final finalLabels = finalvarsRaw
        .split(',')
        .map((s) => s.trim())
        .where((s) => s.isNotEmpty)
        .toSet();
    final finalIds = finalLabels.map((l) => labelToId[l]).whereType<String>().toSet();

    final idToLabel = {
      for (final entry in labelToId.entries) entry.value: entry.key,
    };

    final variables = <ParsedVariable>[];
    for (final entry in resolved.roles.entries) {
      final id = entry.key;
      final role = entry.value;
      final label = idToLabel[id] ?? id;
      final isFinal = role == VarRole.output && finalIds.contains(id);
      variables.add(ParsedVariable(
        identifier: id,
        displayLabel: label,
        role: role,
        isFinal: isFinal || (role == VarRole.output && finalIds.isEmpty),
      ));
    }

    return ParsedEntry(
      name: name,
      description: description == null || description.isEmpty ? null : description,
      equations: equationsParsed,
      variables: variables,
    );
  }

  /// Walks an AST and replaces Identifier nodes via [idFor]. This is needed
  /// because the legacy parser emits identifiers based on what the formula
  /// text contained; we want them to match the slugified labels we'll show.
  /// In the current dump, identifiers in equations are already valid (no
  /// spaces/parens — those quirks appear only in LHS labels like "y(t) air"),
  /// so this is mostly a pass-through. We keep the remap as a safety net.
  static AstNode _remapAst(AstNode node, String Function(String) idFor) {
    return switch (node) {
      NumberLit() => node,
      Identifier(:final name) => OpRegistry.constants.containsKey(name)
          ? node
          : Identifier(idFor(name)),
      UnaryMinus(:final operand) => UnaryMinus(_remapAst(operand, idFor)),
      BinaryOp(:final op, :final left, :final right) =>
        BinaryOp(op, _remapAst(left, idFor), _remapAst(right, idFor)),
      FunctionCall(:final name, :final args) =>
        FunctionCall(name, args.map((a) => _remapAst(a, idFor)).toList()),
    };
  }

  /// Splits on top-level commas only — commas inside parens are preserved.
  static List<String> _splitTopLevelCommas(String src) {
    final pieces = <String>[];
    final buf = StringBuffer();
    var depth = 0;
    for (final r in src.runes) {
      final c = String.fromCharCode(r);
      if (c == '(') depth++;
      if (c == ')') depth--;
      if (c == ',' && depth == 0) {
        pieces.add(buf.toString().trim());
        buf.clear();
        continue;
      }
      buf.write(c);
    }
    if (buf.toString().trim().isNotEmpty) pieces.add(buf.toString().trim());
    return pieces;
  }

  /// Returns the index of the first top-level "=" (not nested in parens), or -1.
  static int _findTopLevelEquals(String src) {
    var depth = 0;
    for (var i = 0; i < src.length; i++) {
      final c = src[i];
      if (c == '(') depth++;
      else if (c == ')') depth--;
      else if (c == '=' && depth == 0) return i;
    }
    return -1;
  }
}
```

// Build-time script.
// Reads ../equationsolver/equations_data.sql and writes assets/migration_seed.json.
//
// Run: dart run tool/build_seed.dart
//
// The input SQL is the output of:
//   pg_restore --data-only --table=equation_solver_equation_solver \
//     --table=equation_solver_folder -f equations_data.sql latest.dump
//
// We parse only the two COPY blocks: equation_solver_equation_solver and
// equation_solver_folder. The COPY format is tab-separated, one row per line,
// terminated by a line containing only "\.".

import 'dart:convert';
import 'dart:io';

const _sourceSqlPath = '../equationsolver/equations_data.sql';
const _outPath = 'assets/migration_seed.json';

void main(List<String> args) {
  final input = args.isNotEmpty ? args[0] : _sourceSqlPath;
  final out = args.length > 1 ? args[1] : _outPath;

  final lines = File(input).readAsLinesSync();
  final equations = _parseCopyBlock(
    lines,
    tableName: 'equation_solver_equation_solver',
    columns: ['id', 'equation', 'variables', 'description', 'folder', 'name', 'finalvars'],
  );
  final folders = _parseCopyBlock(
    lines,
    tableName: 'equation_solver_folder',
    columns: ['id', 'name'],
  );

  final seedFolders = [
    for (final f in folders)
      {
        'old_id': int.parse(f['id']!),
        'name': f['name'],
      },
  ];
  final seedEntries = [
    for (final e in equations)
      {
        'old_id': int.parse(e['id']!),
        'old_folder_id': int.parse(e['folder']!),
        'name': e['name'],
        'description': e['description'],
        'equations_raw': e['equation'],
        'variables_raw': e['variables'],
        'finalvars_raw': e['finalvars'],
      },
  ];

  final seed = {
    'folders': seedFolders,
    'entries': seedEntries,
  };

  Directory(out.substring(0, out.lastIndexOf('/'))).createSync(recursive: true);
  File(out).writeAsStringSync(JsonEncoder.withIndent('  ').convert(seed));
  stdout.writeln(
      'Wrote $out — ${seedFolders.length} folders, ${seedEntries.length} entries.');
}

List<Map<String, String>> _parseCopyBlock(
  List<String> lines, {
  required String tableName,
  required List<String> columns,
}) {
  final result = <Map<String, String>>[];
  final startMarker = RegExp(r'^COPY "public"\."' + tableName + r'"');
  var inBlock = false;
  for (final line in lines) {
    if (!inBlock && startMarker.hasMatch(line)) {
      inBlock = true;
      continue;
    }
    if (inBlock) {
      if (line == r'\.') break;
      final parts = line.split('\t');
      if (parts.length != columns.length) {
        throw StateError(
            'Expected ${columns.length} columns for $tableName, got ${parts.length} in line: $line');
      }
      final row = <String, String>{};
      for (var i = 0; i < columns.length; i++) {
        row[columns[i]] = _decodeCopyField(parts[i]);
      }
      result.add(row);
    }
  }
  if (result.isEmpty) {
    throw StateError('No rows found for $tableName');
  }
  return result;
}

/// Postgres COPY format escape decoder.
/// `\N` -> NULL (surfaced as empty string), `\\` -> `\`, `\n` -> newline,
/// `\t` -> tab, `\r` -> carriage return. Any other character after a
/// backslash is preserved as-is (the backslash is kept verbatim).
String _decodeCopyField(String s) {
  if (s == r'\N') return '';
  final sb = StringBuffer();
  for (var i = 0; i < s.length; i++) {
    if (s.codeUnitAt(i) == 0x5C /* '\' */ && i + 1 < s.length) {
      final next = s[i + 1];
      switch (next) {
        case r'\': sb.write(r'\'); break;
        case 'n':   sb.write('\n'); break;
        case 't':   sb.write('\t'); break;
        case 'r':   sb.write('\r'); break;
        default:    sb.write(r'\'); sb.write(next); break;
      }
      i++;
    } else {
      sb.write(s[i]);
    }
  }
  return sb.toString();
}

/// Substitutes 1.0 for every input-role variable, then evaluates each equation
/// in topo order. Throws if any equation evaluates to NaN/Inf or an EngineError.
void _smokeEvaluate(ParsedEntry entry) {
  final inputs = entry.variables
      .where((v) => v.role == VarRole.input)
      .map((v) => v.identifier);
  final scope = <String, double>{for (final id in inputs) id: 1.0};

  // We need topo order: re-run the resolver on these equations.
  final eqs = entry.equations
      .map((e) => EqEntry(output: e.outputVar, ast: e.ast))
      .toList();
  final resolved = DependencyResolver.resolve(eqs);

  for (final outputName in resolved.order) {
    final eq = entry.equations.firstWhere((e) => e.outputVar == outputName);
    final v = Evaluator(scope: scope).eval(eq.ast);
    scope[outputName] = v;
  }
}

# Engine layer

Pure Dart math engine. **No Flutter imports.** Enforced by
`test/engine/purity_test.dart`.

## Components

- `ast.dart` — sealed `AstNode` hierarchy: `NumberLit`, `Identifier`,
  `UnaryMinus`, `BinaryOp`, `FunctionCall`.
- `ast_json.dart` — `astToJson` / `astFromJson` (lossless) + `prettyPrint`
  (parser-symmetric formatter used for round-trip tests).
- `op_registry.dart` — **the single source of truth for operations**.
  Adding an operation = one entry in `OpRegistry.functions`. Tokenizer,
  parser, evaluator, and UI palette all dispatch via this registry.
- `tokenizer.dart` — produces a flat `List<Token>`.
- `parser.dart` — Pratt parser; precedence: `^` > unary `-` > `* /` > `+ -`,
  right-assoc on `^`. Only used for legacy import + future power-user paste.
- `errors.dart` — `EngineError` sealed hierarchy. Every error has a plain-
  English `userMessage` (never expose `toString()` to users).
- `evaluator.dart` — recursive walk against a `scope` map, with explicit
  domain checks (÷0, log≤0, √<0).
- `dependency_resolver.dart` — Kahn's algorithm topo-sort + cycle detection;
  classifies every identifier as input / intermediate / output.
- `slugify.dart` — `label → identifier` with collision-suffix allocator.
- `legacy_importer.dart` — JSON seed → `ParsedFolder`/`ParsedEntry` list.
- `parsed_entry.dart` — in-memory models the importer emits.

// In op_registry.dart
'asin': OpDef('asin', 1, OpCategory.trigInverse, (a) => math.asin(a[0])),

`OpRegistry.byCategory()`. The parser accepts it as a function call. The
evaluator dispatches via `OpRegistry.lookup(name)`. **Do not** add ad-hoc
branches in evaluator/parser for specific functions — keep all knowledge
in the registry.
